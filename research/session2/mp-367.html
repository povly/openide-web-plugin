Обзор

Плагин OpenIDE Frontend/Web предоставляет расширенную поддержку фронтенд-разработки на TypeScript/JavaScript и современных фреймворках (React, Angular, Vue, Next.js). А также поддержку ESLint и CSS.

TypeScript и JavaScript

  • Поддержка JSX
  • Показ и обновление ошибок TypeScript в реальном времени
  • Переход к определению (Go to)
  • Поиск всех упоминаний (Find References)
  • Поддержка типов и автодополнение
  • Hover-информация
  • Рефакторинги:
    • Add braces to arrow function
    • Convert to named/anonymous/async function
    • Remove unused declaration
    • Add missing attributes
    • Extract to type alias
    • Move to new file
    • Extract to new function
    • Surround with…
    • Convert require → import
    • Infer function return type
    • Rename file/component

Фреймворки

Vue

  • Предложения тэгов
  • Автодополнения аттрибутов
  • Проверка импортов (существование путей, использование комопонета)
  • Автокомплит текстовых интерполяций
  • Диагностика типов в интерполяции
  • Автокомплит обработчиков событий и динамических свойств
  • Автокомплит селекторов стилей
  • Переход к селектору стилей из шаблона
  • Поддержка Emmet в шаблоне

React

  • Автозакрытие тэгов
  • Автоимпорты и автодополнения

Angular

  • Подсветка синтаксиса шаблонов
  • Подсказки типов в шаблонах
  • Переход к комопонету и переменным из шаблона
  • Поддержка аннотаций и декораторов
  • Генерация кода с использованием схем из контекстного меню струкутры проекта

ESLint

  • Поддержка всех распространённых конфигураций ESLint
  • Диагностика и предложения исправлений

CSS и препроцессоры

  • Поддержка CSS, SCSS и Less
  • Подсветка переменных
  • Автодополнение классов и стилей
  • Поддержка цветовых палитр и inline preview

Общее

  • Генератор приоржений React/Vue/Nextjs/Angular
  • Запуск скриптов и установка зависимостей из package.json
  • Подсветка синтаксиса
  • Подсветка ошибок
  • Предложение автодополнений
  • Документация по ховеру

Окружение и настройка

Для работы Frontend/Web требуется плагин LSP4IJ версии 0.19.4.4 и Node.js версии 20.19.0 и выше. Если путь до исполняемого файла Node.js не определился автоматически, его нужно указать в настройках Settings -> Languages & Frameworks -> Frontend/Web -> Path to Node.js. После применения настроек может быть необходимо перезапустить IDE.
